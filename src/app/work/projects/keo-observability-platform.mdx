## Overview

Keo is an observability platform that brings metrics, logs, and deployment activity into one place, with AI-powered anomaly detection to help teams spot issues sooner.

## What I Built

- Built a platform for monitoring metrics, logs, deployments, and AI-powered anomaly detection.
- Developed the backend with Next.js, PostgreSQL, Prisma, Redis Streams, and Socket.IO to support real-time telemetry.
- Deployed the frontend on Vercel, with dedicated Socket.IO and Worker services running on Azure App Service.

## Technologies

- **Frontend:** Next.js, React, Tailwind CSS
- **Backend:** Next.js, PostgreSQL, Prisma, Redis Streams, Socket.IO
- **Deployment:** Vercel, Azure App Service
